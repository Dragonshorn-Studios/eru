# Eru shape

Read [AGENTS.md](../../../AGENTS.md) first. Do not renegotiate the product.

- Eru is a **durable** repo map in SQLite. Maomao is an ephemeral Repo brief on a checkout SHA. Never merge the two. Never call this Eruka. Never DeepWiki.com SaaS.
- Capsule: `I'm curious about this repo.` Tabs: `Brief` · `Ask`. Topbar: mint flower seal + Eru + owner/repo + `last mapped @ref`.
- Stack locks: **Node >= 22 + TypeScript**, **Hono**, **better-sqlite3**, **HTMX + Tailwind + CSS variables**, OpenCode with deny bash/edit/write/webfetch, MIT, Compose. No React SPA for chrome, no Redis, no Postgres, no K8s, no GraphQL.
- Tokens (locked): cream `#F7F5F0`, lavender `#E9E4F7`, pink `#FBE9EC`, ink `#1B1A18`, mint `#CDE8DF`, moss `#A8B99A`, rose `#FADADD`. Serif titles, sans body, mono paths. Soft radius. Pastel glow. No vine/hair chrome, no character art.
- One path per slice. Extend `src/`. Run `npm test` and `npm run typecheck`. If blocked, stop and report — do not invent a second stack, second UI, or second datastore.
